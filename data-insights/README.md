# Data Insights

A simple browser-based tool that analyses a CSV file and shows summary
statistics, key findings, distributions, a scatter plot and a correlation heatmap.

## Files
- index.html      Page structure
- style.css       Styling (light and dark themes)
- script.js       All logic: CSV parsing, statistics, charts
- sample-data.csv A small CSV to try

## How to run
1. Unzip the folder.
2. Open index.html in Chrome, Edge or Firefox (internet needed for the Chart.js and PapaParse libraries).
3. Click "Choose CSV file" (try sample-data.csv) or "Try sample sales data".

## Libraries (loaded from CDN)
- Chart.js 4.4.1
- PapaParse 5.4.1
